# Documentation archive

Historical reports, plans, specifications, and protected planning documents
are retained here when they no longer describe an active production surface.
The live repository keeps only recent reports, CI-referenced baselines, open
work for PR6b/PR7/post-production, and specifications for active modules.

The complete historical set is also preserved on branch `archive/2026-09`.
This directory is not a runtime input and must not be used as an application
source. When a historical decision is needed, cite the original path and date
and copy only the current decision into an active document.
