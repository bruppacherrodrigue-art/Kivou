# PR7 Shadow Acquisition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** run Hermes’ production acquisition chain in immutable SHADOW mode for one selected vertical and region, persist auditable generated mails, and expose review/stats without any send path.

**Architecture:** Keep the existing acquisition domain boundaries, but introduce a production scope (`general_building × Auvergne-Rhône-Alpes`) at selection time. Supplier search receives precise CPV/need terms and a bounded narrowing loop; every provider request and rejection is persisted with the cycle. Personalization persists one shadow mail per procedure/signal/day, while the Instantly gateway rejects all send attempts in SHADOW. Review and stats read those durable records.

**Tech Stack:** Python 3.12, SQLAlchemy Core, Alembic, Pydantic v2, pytest, systemd, PostgreSQL, Apollo, Instantly.
