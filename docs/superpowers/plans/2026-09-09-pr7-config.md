# PR7-config Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add validated fixed/dynamic acquisition configuration, deterministic staging providers, cycle abandonment, and structural host-config drift checks without changing acquisition or billing behavior beyond the approved shadow runtime.

**Architecture:** Extend the existing Pydantic deployment contract with a `selection` object and a `providers` object. Runtime composition selects from either the explicit allowlist or the existing PR7 dynamic selector, and wires deterministic fake Apollo clients only for staging. The deploy script recursively checks required JSON keys and JSON types while deliberately ignoring scalar values, array contents, and host-only extras.

**Tech Stack:** Python 3, Pydantic, SQLAlchemy, pytest, Bash/systemd, JSON.
